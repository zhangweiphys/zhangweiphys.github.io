从零开始搭建GitHub个人主页：Hexo+Butterfly主题实战指南

发表于2026-06-02|更新于2026-06-02|技术教程
|浏览量:

前言

一直想拥有一个属于自己的个人主页，既能展示学术成果，又能写点技术随笔。在折腾了一下午后，终于成功把基于 Hexo + Butterfly 主题 的博客部署到了 GitHub Pages。这篇文章记录完整的踩坑过程，供后来者参考。

最终效果：访问 zhangweiphys.github.io 即可看到成品。

二、本地搭建 Hexo

2.1 环境准备

在电脑上选一个文件夹（建议放固态硬盘，npm 安装和生成速度更快），确保已安装 Node.js 和 Git：

软件 下载地址 验证命令
Node.js (LTS) https://nodejs.org node -v
Git https://git-scm.com git -v

我本地的版本：node v24.15.0，npm 11.12.1。

2.2 初始化 Hexo

依次执行以下命令：

# 1. 安装 Hexo 脚手架（全局）
npm install -g hexo-cli

# 2. 初始化博客项目
hexo init blog
cd blog
npm install
踩坑记录：国内网络访问 GitHub 不稳定，hexo init 时可能会提示 git clone failed. Copying data instead。这是 Hexo 的自动降级机制，会从本地内置模板复制数据，不影响使用，继续往下走即可。

三、安装 Butterfly 主题
3.1 下载主题
由于国内直连 GitHub 经常超时，建议直接用浏览器下载 ZIP 包：
1.浏览器打开：https://github.com/jerryc127/hexo-theme-butterfly
2.点击绿色 Code → Download ZIP
3.解压到 blog/themes/ 文件夹下
4.关键：把文件夹重命名为 butterfly（Hexo 只认这个名字，否则报找不到主题）
3.2 安装渲染依赖
npm install hexo-renderer-pug hexo-renderer-stylus --save
3.3 启用主题
打开 blog/_config.yml，找到 theme: 这一行，改为：
theme: butterfly
3.4 验证主题是否生效
hexo clean
hexo g
hexo s
浏览器访问 http://localhost:4000，如果看到蓝色封面 + 向下箭头，点击箭头后进入白色文章列表页，说明 Butterfly 主题已成功加载。
踩坑记录：如果还是显示旧的 Hexo 默认页面，大概率是浏览器缓存或旧的 Node 进程占用了 4000 端口。解决方案： 1. 强制刷新：Ctrl + Shift + R 2. 或换端口启动：hexo s -p 4001 3. 或杀掉旧进程：Get-Process node | Stop-Process 后再启动

四、主题美化配置
在 blog 根目录下创建 _config.butterfly.yml，写入以下核心配置。
4.1 首页封面与头像
# 首页顶部背景图
index_img: /img/cover1.jpg

# 头像（侧边栏显示）
avatar:
  img: /img/avatar.jpg
  effect: false

# 各页面顶部背景（时间轴、标签、分类）
archive_img: /img/cover1.jpg
tag_img: /img/cover1.jpg
category_img: /img/cover1.jpg
图片统一放在 blog/source/img/ 目录下，Hexo 生成时会自动复制到 public/img/。引用时用绝对路径 /img/xxx.jpg，这样部署到任何域名都能正常显示。
4.2 打字机副标题效果（临江仙）
subtitle:
  enable: true
  effect: true
  startDelay: 300
  typeSpeed: 150
  backSpeed: 50
  loop: true
  source: false
  sub:
    - 滚滚长江东逝水，浪花淘尽英雄
    - 是非成败转头空，青山依旧在，几度夕阳红
    - 白发渔樵江渚上，惯看秋月春风
    - 一壶浊酒喜相逢，古今多少事，都付笑谈中
4.3 导航栏菜单
menu:
  首页: / || fas fa-home
  时间轴: /archives/ || fas fa-archive
  标签: /tags/ || fas fa-tags
  分类: /categories/ || fas fa-folder-open
  链接: /link/ || fas fa-link
  关于: /about/ || fas fa-heart
4.4 鼠标特效
# 鼠标点击烟花
fireworks:
  enable: true
  zIndex: 9999
  mobile: false

五、解决 404 页面问题
配置好导航栏后，点击”标签”和”分类”会报 404，因为对应的页面文件还没生成。
5.1 生成分类和标签页面
hexo new page categories
hexo new page tags
hexo new page about
hexo new page link
5.2 修改页面类型
编辑 source/categories/index.md：
---
title: 分类
date: 2026-06-01 00:00:00
type: categories
top_img: /img/cover1.jpg
---
编辑 source/tags/index.md：
---
title: 标签
date: 2026-06-01 00:00:00
type: tags
top_img: /img/cover1.jpg
---
编辑 source/about/index.md：
---
title: 关于
date: 2026-06-01 00:00:00
type: about
top_img: /img/cover1.jpg
---
编辑 source/link/index.md：
---
title: 链接
date: 2026-06-01 00:00:00
type: link
top_img: /img/cover1.jpg
---
5.3 友链数据
创建 source/_data/link.yml（注意：必须是 source/_data/ 目录，不是 source/link/）：
- class_name: 友链
  class_desc: 小伙伴
  link_list:
    - name: zhangweiphys
      link: https://example.com
      avatar: /img/avatar.jpg
      descr: Myself

- class_name: 网站
  class_desc: 一气化三清
  link_list:
    - name: 知乎
      link: https://zhihu.com
      avatar: /img/zhihu.jpg
      descr: Ustinian

六、部署到 GitHub Pages
6.1 安装部署插件
npm install hexo-deployer-git --save
6.2 配置部署信息
打开 blog/_config.yml，在末尾添加：
deploy:
  type: git
  repo: https://github.com/zhangweiphys/zhangweiphys.github.io.git
  branch: main
6.3 配置 Git 身份（首次必需）
git config --global user.name "zhangweiphys"
git config --global user.email "你的邮箱@example.com"
6.4 执行部署
PowerShell 不支持 &&，必须分开执行：
hexo clean
hexo g
hexo d
踩坑记录：国内 Git 连接 GitHub 不稳定，如果报错 Connection was reset，可以配置 Git 走代理：
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
其中 7890 是你的梯子本地代理端口（Clash 默认一般是 7890）。如果梯子关闭后想直连，取消代理：
git config --global --unset http.proxy
git config --global --unset https.proxy
部署成功后，终端会显示 Deploy done: git，然后访问 https://zhangweiphys.github.io 即可。

七、后续写作与维护流程
以后每写一篇新文章，只需要三步：
# 1. 创建文章
hexo new post "文章标题"

# 2. 编辑 source/_posts/文章标题.md

# 3. 生成并部署
hexo clean
hexo g
hexo d
常用命令速查
命令	作用
hexo clean	清空缓存和 public 文件夹
hexo g	生成静态网页（generate）
hexo s	启动本地预览服务器（server）
hexo d	部署到 GitHub（deploy）
hexo new post "标题"	创建新文章
hexo new page "页面"	创建独立页面

八、总结
从一张简单的 index.html 到完整的 Hexo + Butterfly 博客，整个过程的核心步骤是：
1.环境准备 → Node.js + Git
2.初始化 Hexo → hexo init
3.安装主题 → Butterfly 手动下载 + 重命名
4.配置美化 → 封面、头像、打字机、导航栏
5.生成页面 → 标签、分类、关于、友链
6.部署上线 → hexo d 推送到 GitHub
虽然过程中遇到了网络超时、Git 代理、404 页面、YAML 缩进等各种小坑，但按照上面的步骤逐一排查，最终都能解决。现在终于拥有了一个可以持续写作的个人主页，以后的研究笔记和技术随笔都可以陆续搬上来了。
我的主页：https://zhangweiphys.github.io
