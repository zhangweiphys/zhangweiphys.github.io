三、安装 Butterfly 主题

3.1 下载主题

由于国内直连 GitHub 经常超时，建议直接用浏览器下载 ZIP 包：

  2. 点击绿色 Code → Download ZIP
  3. 解压到 blog/themes/ 文件夹下
  4. **关键：把文件夹重命名为 butterfly**（Hexo 只认这个名字，否则报找不到主题）

浏览器访问 http://localhost:4000，如果看到蓝色封面 + 向下箭头，点击箭头后进入白色文章列表页，说明 Butterfly 主题已成功加载。

踩坑记录：如果还是显示旧的 Hexo 默认页面，大概率是浏览器缓存或旧的 Node 进程占用了 4000 端口。解决方案：

  1. 强制刷新：Ctrl + Shift + R
  2. 或换端口启动：hexo s -p 4001
  3. 或杀掉旧进程：Get-Process node | Stop-Process 后再启动

命令 作用

hexo s 启动本地预览服务器（server）
hexo d 部署到 GitHub（deploy）
hexo new post "标题" 创建新文章
hexo new page "页面" 创建独立页面

八、总结

从一张简单的 index.html 到完整的 Hexo + Butterfly 博客，整个过程的核心步骤是：

  1. 环境准备 → Node.js + Git
  2. 初始化 Hexo → hexo init
  3. 安装主题 → Butterfly 手动下载 + 重命名
  4. 配置美化 → 封面、头像、打字机、导航栏
  5. 生成页面 → 标签、分类、关于、友链
  6. 部署上线 → hexo d 推送到 GitHub

虽然过程中遇到了网络超时、Git 代理、404 页面、YAML 缩进等各种小坑，但按照上面的步骤逐一排查，最终都能解决。现在终于拥有了一个可以持续写作的个人主页，以后的研究笔记和技术随笔都可以陆续搬上来了。
