一、前置条件与准备工作

1.1 系统要求

项目 最低要求
操作系统 Windows 10（需内部版本19041+）或 Windows 11(可通过 Win + R，并输入 winver 来查看版本号)
CPU 支持虚拟化（BIOS 中需开启）
磁盘空间 建议预留 10GB+

1.2 需要下载的软件

软件 下载地址 说明
Visual Studio Code https://code.visualstudio.com/download 代码编辑器
Ubuntu (WSL) Microsoft Store 搜索 “Ubuntu” Linux 发行版

1.3 确认 BIOS 虚拟化已开启

打开任务管理器 → 性能 → CPU → 查看右下角”虚拟化：已启用”。

⚠️ 如果显示”已禁用”，需要重启进入 BIOS，找到 Intel Virtualization Technology 或 AMD-V，将其设为 Enabled。

三、安装 Ubuntu 发行版

3.1 通过 Microsoft Store 安装（推荐）

  1. 打开 Microsoft Store
  2. 搜索 “Ubuntu” （推荐安装 Ubuntu 24.04 ）
  3. 点击 “获取” → “安装”
  4. 安装完成后点击 “打开”

3.2 安装位置说明

安装方式 默认位置
Microsoft Store C:\Users\<用户名>\AppData\Local\Packages\CanonicalGroupLimited.Ubuntu...\LocalState\ext4.vhdx
wsl --install 同上

⚠️ 默认安装在 C 盘。如果 C 盘空间紧张，可以在安装后迁移（详见第十节）。

3.3 WSL 设置管理工具

安装 WSL 后，Windows 会自动提供一个 “WSL 设置” 管理界面（可在开始菜单搜索 “WSL” 找到）。

问题 答案
它是什么 Windows 系统自带的 WSL 管理界面（类似控制面板）
需要保持打开吗 ❌ 不需要，关闭不影响任何功能
和 Ubuntu 的区别 它是管理工具，Ubuntu 是实际的 Linux 系统

3.4 文件资源管理器中的 “Linux” 入口

安装 Ubuntu 后，Windows 资源管理器左侧会出现一个 “Linux” 入口：

  • 实际路径：\\wsl$\Ubuntu\ 或 \\wsl.localhost\Ubuntu\
  • 是 Windows 自动注册的快捷入口，方便浏览 Linux 文件
  • 卸载所有 WSL 发行版后会自动消失

💡 配置说明：

  • systemd=true：启用 systemd 服务管理（某些工具需要）
  • interop=true：允许在 WSL 中运行 Windows 程序（如 code .）

4.4 WSL 文件系统结构理解

类型 路径示例 实际存储位置 性能
Linux 文件系统 /home/,/usr/,/etc/ ext4.vhdx虚拟磁盘 ✅ 原生性能，快
Windows 挂载 /mnt/c/,/mnt/d/,/mnt/e/ 对应 Windows 各盘符 ⚠️ 跨系统访问，较慢

🔑 核心原则 ：所有开发工作（git clone、项目文件、虚拟环境等）都应放在 Linux 文件系统内（/home/<用户名>/ 下），不要放在 /mnt/ 路径下！

七、安装与配置 VS Code

7.1 安装 VS Code

从官网下载并安装：https://code.visualstudio.com/download

安装时建议勾选：

  • ✅ 添加到 PATH
  • ✅ 添加”通过 Code 打开”操作到文件/文件夹右键菜单

7.2 安装必备扩展

打开 VS Code打开扩展商店，安装以下扩展：

扩展名称 安装位置 说明
WSL(ms-vscode-remote.remote-wsl) Windows 侧 🔑核心扩展 ，连接 WSL
Python (ms-python.python) WSL 侧 Python 语言支持

💡 重要概念 ：VS Code 的扩展分为两类：

  • 本地 UI 扩展 （主题、代码片段等）→ 安装在 Windows 侧
  • 功能扩展 （Python、调试器等）→ 需要安装在 WSL 侧 （点击 “Install in WSL”）

7.3 安装 WSL 扩展

  1. 打开 VS Code
  2. 按 Ctrl+Shift+X 打开扩展面板
  3. 搜索 “WSL”
  4. 安装 “WSL” 扩展（发布者：Microsoft）

安装后，VS Code 左下角状态栏会出现一个远程连接指示器。

八、VS Code 连接 WSL 远程开发

8.1 方式一：从 WSL 终端打开

📌 首次执行 code . 时，VS Code 会自动：

  1. 在 WSL 中安装 VS Code Server （一个小型服务端程序）
  2. 安装到 ~/.vscode-server/ 目录
  3. 之后 Windows 端的 VS Code 通过这个 Server 与 WSL 通信

8.2 方式二：从 VS Code 中打开 WSL

  1. 按 Ctrl+Shift+P 打开命令面板
  2. 输入 WSL
  3. 选择 “WSL: Connect to WSL” 或 “WSL: Connect to WSL Using Distro…”

8.3 验证连接成功

连接成功后：

  • 左下角状态栏显示 “WSL: Ubuntu”
  • 打开终端（快捷键 Ctrl+` ）自动进入 WSL bash
  • 文件路径显示为 Linux 路径（如 /home/yourname/projects/）

8.4 在 VS Code WSL 中安装扩展

连接 WSL 后，打开扩展面板（Ctrl+Shift+X），你会看到：

  • Local – Installed ：Windows 侧的扩展
  • WSL: Ubuntu – Installed ：WSL 侧的扩展

需要在 WSL 侧安装的扩展，点击 “Install in WSL” 按钮。

九、Python 虚拟环境配置

9.1 为什么需要虚拟环境？

虚拟环境为每个项目创建独立的 Python 运行环境，包含：

  • 独立的 Python 解释器
  • 独立的 pip 包安装目录
  • 独立的 site-packages

核心作用 ：隔离不同项目的依赖，避免包版本冲突。

9.5 方案对比

方案 特点 适用场景 自由切换

十、WSL 磁盘迁移（C盘→其他盘）

10.1 为什么需要迁移？

  • WSL 默认安装在 C 盘：C:\Users\<用户名>\AppData\Local\Packages\...\ext4.vhdx
  • ext4.vhdx 是虚拟磁盘文件，初始约 500MB-1GB，使用中可能增长到 10GB+
  • VHDX 只增不减 （即使删除 Linux 内文件，VHDX 大小也不会自动缩小）

附录：快速命令速查表

WSL 管理命令（在 Windows PowerShell 中执行）

命令 说明
wsl 启动默认 WSL 发行版
wsl -l -v 列出所有发行版及状态
wsl --shutdown 关闭所有 WSL 发行版
wsl --terminate Ubuntu 关闭指定发行版
wsl --install -d Ubuntu-24.04 安装指定发行版
wsl --export Ubuntu backup.vhdx --vhd 导出发行版
wsl --import Ubuntu 路径 backup.vhdx --vhd 导出发行版
wsl --unregister Ubuntu ⚠️ 注销（删除）发行版
wsl --update 更新 WSL
wsl --version 查看 WSL 版本

常用 WSL 内部命令

命令 说明
code . 用 VS Code 打开当前目录
notepad.exe 测试 Windows 互操作
explorer.exe . 在 Windows 资源管理器中打开当前目录
which code 查看 code 命令路径
cat /etc/wsl.conf 查看 WSL 配置
df -h 查看磁盘空间
du -sh ~/* 查看各目录大小

Git 常用命令

命令 说明
git clone <url> 克隆仓库
git status 查看状态
git add . 暂存所有更改
git commit -m "msg" 提交
git push 推送到远程
git pull 拉取远程更新

Python 虚拟环境命令

命令 说明
python3 -m venv .venv 创建虚拟环境
source .venv/bin/activate 激活虚拟环境
deactivate 退出虚拟环境
pip freeze > requirements.txt 导出依赖
pip install -r requirements.txt 安装依赖
pip list 查看已安装的包
